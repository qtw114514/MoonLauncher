## v0.0.3 人性化与易用性改进建议

> 版本目标：核心下载与启动能力已经较完整，本版本优先减少新手的学习成本和重复操作，让“选择账号 → 选择版本 → 启动游戏”成为一条清晰、可恢复的主流程。默认设置应能直接玩，高级选项不阻碍普通用户。

| 优先级 | 建议 | 操作逻辑与交互改进 | 完成标准 |
|---|---|---|---|
| P0 | **首次启动引导与一键启动** | 首次打开用简短引导完成账号添加、游戏目录确认和版本安装；之后首页默认选中上次使用的账号与版本，直接点击“启动游戏”。未配置时，启动按钮应引导用户补齐缺失项，而不是只报错；Java、内存和镜像默认自动处理，允许跳过引导。 | 新用户无需阅读文档即可进入游戏；老用户再次打开后无须重复选择账号和版本。 |
| P0 | **明确当前状态，避免重复启动** | 首页持续显示当前账号、游戏目录和版本；游戏运行时把主按钮改为“游戏运行中”，提供“查看日志”和“结束游戏”，禁止无提示地再次启动。启动中、运行中、已退出和启动失败应有明显且一致的状态。 | 不会因重复点击生成两个相互干扰的游戏会话；运行状态与日志始终对应同一游戏进程（同时处理评审记录 N1）。 |
| P0 | **下载与安装任务可理解、可恢复** | 将“校验文件、下载、安装加载器、安装 Java”等步骤汇总为面向用户的阶段进度，显示当前操作、速度、剩余项；支持暂停、继续、取消和失败重试。失败提示先说明“哪一步没完成、可以怎么办”，技术详情默认折叠，并提供“重试”和“复制诊断信息”。 | 下载或安装失败后可直接从原任务重试，不要求用户返回首页重新操作；断网恢复、换源和重试状态清楚可见。 |
| P0 | **危险操作先说明后果，并支持挽回** | 删除、覆盖、重命名和批量更新前，用简洁确认框列出受影响对象；重命名版本时同步处理继承关系，替换同名资源时提示归属，不静默覆盖手动加入的文件。运行中的版本禁止删除；能进回收站或撤销的操作提供明确入口。 | 不出现静默覆盖、重命名后继承版本损坏或运行中误删；确认文案说明具体影响而非只问“是否确定”（关联 N2、N3）。 |
| P1 | **资源安装沿用当前版本上下文** | 从某个版本进入 Mod、资源包或光影下载时，自动带入该版本的 MC 版本、加载器和目标目录；默认只显示兼容结果，并允许一键查看全部。安装前列出将新增、更新和自动补装的前置文件，成功后提供“打开管理页”。 | 用户不必在搜索页重复选择版本和加载器，也不会把资源误装到其他游戏目录；安装结果和去向清晰可见。 |
| P1 | **账号登录按用户任务组织** | 将离线、微软和外置登录分别说明适用场景；微软登录未配置 Client ID 时，在登录入口直接给出原因、配置入口及离线/外置替代方案。设备代码流程提供“一键复制并打开浏览器”、剩余时间和登录结果反馈；令牌失效时提供“重新登录”而不是仅显示异常。 | 用户能在登录页内解决常见配置和授权问题，无须频繁跳转文档；登录状态与当前使用账号一致。 |
| P1 | **统一错误处理与一键修复** | 启动失败、资源加载失败和崩溃分析统一采用“原因摘要 → 推荐操作 → 技术详情”的结构；对缺少 Java、内存不足、缺少前置、网络失败等已知问题提供对应按钮，如“自动安装 Java”“调整内存”“补装前置”“重试”。 | 每个常见失败页面都有下一步操作；详情页加载失败可直接重试（关联 N7），导出报告前保留原始日志。 |
| P2 | **简化设置并统一页面操作** | 设置分为“常用”和“高级”，普通用户只接触账号、目录、下载和外观等常用项；Java 参数、JVM 参数等集中放入高级设置，并提供作用说明和恢复默认值。统一返回、保存、搜索、筛选、空状态和成功提示，关键操作支持键盘与拖放。 | 常用设置无需理解技术术语；未保存修改有提示，筛选条件和返回行为一致，空白页面始终告诉用户下一步能做什么。 |

### 推荐实施顺序

1. 先完成主流程和安全性：首次启动引导、一键启动、运行状态、防误操作。
2. 再完善任务反馈与恢复：下载安装重试、统一错误处理、账号登录引导。
3. 最后做上下文联动和界面一致性，避免 v0.0.3 同时引入过多页面重构。
4. 每项改进至少覆盖“首次使用、正常完成、网络失败、重复点击、取消后重试”五类场景，再进入下一项。

## 路线图（按优先级）

1. **v0.0.3 人性化与易用性**：优先落实上方 P0 / P1 项，以完整走通新手启动、失败恢复和资源安装流程为验收目标。
2. **联机**：集成 EasyTier，房间码一键加入；把房主的局域网广播转发到本地，让好友在“多人游戏”列表里直接看到。
3. **CurseForge 指纹查更新**：用 MurmurHash2 指纹调用 CurseForge 接口，覆盖 CurseForge 独有的 Mod。
4. **社区中文词表**：把 `zh-names.json` 做成可社区维护的独立仓库，随签名清单下发。
5. 离线皮肤、正版换皮肤、存档备份、服务器列表。
